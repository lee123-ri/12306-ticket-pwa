# 火车票助手（12306 查票 / 余票监控 PWA）

个人自用的 12306 工具：手机浏览器打开即用，**问票、收通知、一键跳转官方购票**。部署在你自己的阿里云服务器上。

## 功能

- **查票**：自然语言问「明天北京到上海二等座」，返回车次、余票、票价。
- **监控**：说「盯一下下周五北京到杭州的二等座」，后台定时轮询，有余票推送通知到手机。
- **快捷买票**：结果带「去 12306 购票」按钮，一键跳到 12306 官方页面，你登录后选人付款即可（**不自动下单**）。
- **PWA**：手机浏览器「添加到主屏幕」后像个 App，支持 Web Push 系统通知。

## 架构

```
手机浏览器（PWA：聊天界面 + Web Push 通知）
        │
        ▼
阿里云服务器（Node.js 后端）
   ├─ 查票：直连 12306 公开查询接口
   ├─ 自然语言解析：DeepSeek（可选）或规则兜底
   ├─ 监控：定时轮询，命中即推 Web Push
   └─ 数据：本地 JSON 持久化（监控任务 + 通知订阅）
```

## 合规边界（重要）

- 查余票 / 票价 / 经停 / 换乘 = 12306 公开接口，**合规可用**。
- 本项目**不自动下单、不模拟登录、不破解验证码**。「快捷买票」只是跳转 12306 官方页面，下单由你本人完成。
- 抢票靠 12306 官方「候补购票」+ 本工具的到点通知，成功率最高且不封号。

## 一、本地运行

```bash
npm install
cp .env.example .env   # 按需修改
npm start
```

浏览器打开 `http://localhost:8080` 即可测试（localhost 下 Web Push 可用）。

## 二、阿里云部署（Docker）

### 第 1 步：装 Docker（一行命令）

```bash
curl -fsSL https://get.docker.com | sh
```

### 第 2 步：加一条子域名解析

到你域名 DNS 面板加一条 **A 记录**，指向服务器公网 IP：

```
类型: A    主机记录: ticket    记录值: 你的服务器IP
```

子域名随意（如 `ticket`），不影响你现有软件用的其它子域名。

### 第 3 步：克隆代码到服务器（git 部署）

```bash
git clone https://github.com/lee123-ri/12306-ticket-pwa.git
```

（仓库已公开，无需身份验证）

### 第 4 步：跑一键部署脚本

```bash
cd 12306-ticket-pwa
bash deploy.sh
```

脚本会交互式问你「子域名」和「DeepSeek key」，然后自动完成：生成配置 → 构建镜像 → 签 HTTPS 证书 → 启动服务 → 健康检查。

### 第 5 步：手机打开

浏览器访问 `https://ticket.你的域名.com`，点「开启通知」+「添加到主屏幕」。

> 提示：证书签发要求第 2 步的 A 记录已生效（DNS 生效可能等几分钟）。部署完用 `curl https://ticket.你的域名.com/api/health` 验证，返回 `{"ok":true}` 即成功。

### 验证

```bash
curl https://ticket.你的域名.com/api/health
# 返回 {"ok":true,...} 即成功
```

## 三、手机端使用

1. 手机浏览器（Chrome/Edge）打开你的 HTTPS 地址。
2. 点右上角「开启通知」，允许通知权限（这是收余票提醒的前提）。
3. 浏览器菜单里点「添加到主屏幕」，桌面出现图标。
4. 聊天框直接问：
   - `明天北京到上海二等座`
   - `8月25日 广州南到长沙 500以内`
   - `盯一下下周五北京到杭州的二等座`（→ 创建监控）
5. 监控任务可在右上角「监控」里暂停 / 删除。

## 四、常见问题

- **收不到通知？** Web Push 只在 HTTPS 下工作；确认手机浏览器允许了该站点通知；iOS Safari 需 16.4+ 且「添加到主屏幕」后才能用。
- **查票失败 / 无返回？** 12306 有反爬，间隔太短会被限流，把 `POLL_INTERVAL_SEC` 调大；或稍后重试。
- **票价怎么没有独立显示？** 票价随余票一起返回，结果里「席别 + 余票 + ¥价格」已合并展示。
